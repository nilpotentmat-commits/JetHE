# Reproduce the ordinary-source alignment checks

From the repository root:

```powershell
python -B SubmissionA/research/eurocrypt-readiness-2026-09-13/same-algebra-source-alignment-v1/check_alignment.py
```

The command uses exact integers/fractions and preserves both implementations' source laws. It binds the existing source-scope receipt, exact control admission, actual native sampler and common workflow driver. Its small enumeration checks the projection direction and unit-2 scaling; the written proof gives the general statement. No cryptographic randomness, encrypted execution, estimator run, concrete attack cost or timing ratio is produced.
